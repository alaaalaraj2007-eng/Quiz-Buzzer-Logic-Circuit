# 🕹️ Quiz Buzzer Logic Circuit using Logisim

A 4-player Quiz Buzzer logic circuit simulation designed using Logisim.

## 📐 Circuit Design
![Quiz Buzzer Circuit](./IMG_20260729_231739.jpg)


## 💡 How it Works
- Features 4 player inputs (`player1`, `player2`, `player3`, `player4`).
- Utilizes Logic Gates and Latches to catch the first button pressed.
- Automatically locks out other players once a winner is registered.
- Includes a **Reset** button to start a new round.
